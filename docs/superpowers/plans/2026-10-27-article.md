# Статья по итогам Neuronoid — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Статья на Хабр (RU) и адаптация для LinkedIn (EN) о том, что LLM — часть ИИ-системы, с иллюстрациями
и проверяемыми цифрами.

**Architecture:** Всё лежит в `docs/article/`. Каждое число в тексте берётся из таблицы фактов `facts.md`
(число → источник). Скрипт `check.py` считает слова и находит в тексте числа, которых нет в таблице. Графики и
пересчёт стоимости строят скрипты из данных проекта, поэтому их можно воспроизвести.

**Tech Stack:** Python 3 (venv проекта, `uv run`), pytest, matplotlib, Markdown.

**Spec:** `docs/superpowers/specs/2026-10-27-article-design.md`

## Global Constraints

- Главная мысль: «ИИ-система — это не только обученная модель; LLM внутри неё может сама разобраться в
  незнакомой задаче и построить решение». Вторая мысль: выводы «ИИ этого не умеет» устаревают за полгода.
- Хабр: русский язык, 1800–2200 слов, 4–5 иллюстраций, структура из 8 разделов спеки (объёмы разделов там же).
- LinkedIn: английский язык; статья 1000–1200 слов, пост 150–250 слов со ссылкой; 2–3 иллюстрации из тех же.
  Это адаптация, не перевод. Пишется после утверждения русской версии автором.
- Текст от первого лица автора (Аскар Жакенов).
- Канеман — одна-две фразы, не каркас статьи.
- Обязательные оговорки (анти-цели спеки):
  - угол отскока в RL-ветке дала подсказка человека, исследователь нашёл его сам;
  - каждую починку запускал человек отдельной задачей — никакого «self-healing»;
  - запрет на интернет — правило задания, технически не закрыт;
  - 101 820 и раунд 9 — на стенде исследователя, 18 минут по коммитам;
  - во второй раунд RL попадал только через капсулу «B»;
  - «тело» и судью сделали мы;
  - стоимость — пересчёт по ценам API, не реальный счёт; подавать как «порядок — десятки долларов».
- Кода в статье нет или почти нет: допускается один короткий фрагмент или таблица замеров.
- Файлы игры (`games/`) и личные данные не публикуются.

## Review Focus

1. Число в тексте без источника или расходится с журналом (например, «час» вместо «18 минут», среднее
   343 977, разброс 324–370 тыс.). Ожидание: каждое число есть в `facts.md` с источником — Task 1 `check.py`.
2. Формулировка, которая преувеличивает: «сам починился», «без помощи человека», «RL не может». Ожидание:
   читатель не уходит с ложным выводом — Task 4, шаг рецензии против анти-целей.
3. Иллюстрация с двумя шкалами или график, где RL и исследователь сравниваются на одной оси времени.
   Ожидание: две отдельные панели — Task 3, тест на число осей.
4. Ссылка на репозиторий, где лежит файл игры или личный путь/почта. Ожидание: перед публикацией
   проверка находит такие файлы — Task 6.
5. LinkedIn-версия, которая стала дословным переводом или потеряла оговорки. Ожидание: те же оговорки,
   та же таблица фактов — Task 5 прогоняет `check.py` с `facts.md`.

### Task 1: Таблица фактов и проверка текста

**Files:**
- Create: `docs/article/facts.md`
- Create: `docs/article/check.py`
- Test: `tests/test_article_check.py`

**Interfaces:**
- Produces:
  - `word_count(text: str) -> int` — слова без Markdown-разметки, ссылок-URL и подписей к картинкам;
  - `numbers_in(text: str) -> set[str]` — числа в нормальной форме: пробелы и неразрывные пробелы внутри
    числа убраны, десятичная запятая заменена точкой; `101 820` → `101820`, `2,5` → `2.5`;
  - `load_facts(path: Path) -> set[str]` — числа из первой колонки таблицы `facts.md` в той же форме;
  - `unverified(text: str, facts: set[str]) -> set[str]` — числа текста, которых нет в facts;
    числа 0–10 не проверяются (порядковые слова, «два-три»);
  - CLI: `python docs/article/check.py <file.md> --min N --max M` печатает число слов и непроверенные числа;
    код выхода 1, если слов вне диапазона или есть непроверенные числа.

def test_unverified_found():
    assert unverified("средний счёт 343 977", {"343970"}) == {"343977"}

def test_word_count_skips_markup_and_urls():
    assert word_count("## Заголовок\n\nДва слова ![подпись](img/a.png) https://x.y") == 3

def test_load_facts(tmp_path):
    p = tmp_path / "facts.md"
    p.write_text("| Число | Что | Источник |\n|---|---|---|\n| 343 977 | среднее | log |\n", encoding="utf-8")
    assert load_facts(p) == {"343977"}
