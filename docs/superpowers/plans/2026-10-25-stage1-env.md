# Этап 1: среда, чтение экрана, живое окно — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gymnasium-среда `ArkanoidEnv`, где агент видит только пиксели и получает награду, прочитанную с экрана, плюс окно, в котором в любой момент можно смотреть игру вживую.

**Architecture:** `ScreenReader` читает счёт, раунд, жизни и «идёт ли игра» с кадра 320×200 по точному совпадению с образцами глифов шрифта игры. `ArkanoidEnv` поверх `LibretroEmulator` даёт дискретные действия мышью, frame skip, предобработку кадра и стек кадров. Награду считает только из `ScreenReader`. Живое окно — отдельный процесс `scripts/watch.py`, который читает последний кадр из общей памяти (`multiprocessing.shared_memory`); среда пишет туда, только если ей включили `live=True`.

**Tech Stack:** Python 3.12, gymnasium, numpy, pygame (только окно), pytest.

**Spec:** `docs/superpowers/specs/2026-10-24-neuronoid-design.md`; факты об экране и эмуляторе — `docs/spike-report.md`.

## Global Constraints

- Память эмулятора не читается нигде: ни для наблюдения, ни для награды, ни для конца эпизода.
- Управление — мышь (`Mouse` из `neuronoid.emulator`), дискретный набор действий.
- Случайность против заучивания: случайное число пустых кадров на старте эпизода и «залипающие» действия.
- Один эмулятор на процесс за всю жизнь процесса.
- Код кроссплатформенный (Windows / macOS), без путей, зашитых под одну ОС.
- Кадры игры для тестов можно хранить в `tests/data/` (личный репозиторий, как и `docs/img/`).

## Review Focus

1. Кадр не игровой: меню 640×400, титульный экран, вступление, затемнение. `ScreenReader` должен вернуть `None`/`False`, а не мусорное число и не исключение. — тест в Task 1 и Task 2.
2. Счёт временно не читается (мигание, перерисовка): среда не должна выдать огромную награду при «скачке» `None → 12000`. Награда считается только между двумя успешно прочитанными значениями, а скачок вниз (сброс) игнорируется. — тест в Task 3.
3. Game Over: после последней жизни игра уходит на титульный экран, затем в демо-режим, похожий на игру. Эпизод должен завершиться (`terminated=True`) до того, как демо-режим начнёт давать «награду». — тест в Task 3.
4. Окно открыто, а обучение не запущено (или наоборот, среда пишет, а окна нет): ни одна сторона не падает и не блокирует другую. — тест в Task 4.
5. `reset(seed=s)` дважды с одним `s` и одинаковые действия дают одинаковые наблюдения и награды (воспроизводимость отладки), а разные `s` дают разные стартовые сдвиги. — тест в Task 3.

### Task 3: `ArkanoidEnv` (Gymnasium)

**Files:**
- Modify: `pyproject.toml` (+ `gymnasium`)
- Create: `neuronoid/env.py`
- Test: `tests/test_env.py`

**Interfaces:**
- Consumes: `LibretroEmulator`, `Mouse`, `boot_to_round1`, `read_state`/`ScreenState`, `config.core_path/game_path`.
- Produces:
  - `ACTIONS: tuple[Mouse, ...] = (Mouse(), Mouse(left=True), Mouse(dx=-4), Mouse(dx=4), Mouse(dx=-12), Mouse(dx=12))` — ничего, огонь (запуск мяча / лазер), медленно и быстро влево/вправо. Скорость ракетки игра ограничивает сама (около 1 и 2,5 пикселя за кадр).
  - `class ArkanoidEnv(gymnasium.Env)`:
    - `__init__(self, frame_skip: int = 4, frame_stack: int = 4, sticky_prob: float = 0.25, max_noop: int = 30, life_loss_terminal: bool = False, max_steps: int = 27_000, live: bool = False)`. Эмулятор создаётся лениво при первом `reset`. Состояние «раунд 1, мяч на ракетке» снимается один раз после `boot_to_round1` и хранится в памяти процесса.
    - `action_space = Discrete(len(ACTIONS))`.
    - `observation_space = Box(0, 255, (frame_stack, 93, 96), uint8)`: игровое поле `frame[4:190, 32:224]` → оттенки серого → уменьшение в 2 раза (среднее по блокам 2×2) → 93×96; берётся поэлементный максимум двух последних кадров frame skip (против мерцания).
    - `reset(seed=None, options=None) -> (obs, info)`: `load_state(старт)`, затем случайное число от 0 до `max_noop` шагов `ACTIONS[0]` по `self.np_random`. Стек заполняется первым кадром.
    - `step(action) -> (obs, reward, terminated, truncated, info)`: с вероятностью `sticky_prob` повторяется предыдущее действие; `emu.step(mouse=ACTIONS[a], frames=frame_skip)` (с отдельным захватом предпоследнего кадра для максимума); `read_state` по последнему кадру.
    - **Награда** (константы на уровне модуля): `SCORE_SCALE = 0.01` × прирост счёта — только между двумя прочитанными значениями и только если прирост > 0 и ≤ `MAX_SCORE_JUMP = 5000` (иначе 0); `LIFE_PENALTY = -1.0`, когда прочитанное `lives` уменьшилось; `ROUND_BONUS = 10.0`, когда прочитанный `round` вырос.
    - **Конец:** `terminated = True`, если `GAME_OVER_FRAMES = 3` шага подряд `playing == False` (титульный экран после Game Over), или при `life_loss_terminal` и потере жизни. `truncated = True` при `max_steps`.
    - `info = {"score": int|None, "round": int|None, "lives": int|None, "playing": bool}`. Кадр в `info` не кладётся: окно читает его из общей памяти (Task 4).
    - Среда хранит `self._known: ScreenState` — последние **прочитанные** значения (поле с `None` в новом кадре не затирает известное). Награда за шаг: `reward_between(self._known, cur)`, затем `self._known` обновляется непустыми полями `cur`.
    - `render()` не реализуется (`render_mode=None`); живой просмотр — через Task 4.
    - `close()` закрывает эмулятор.

```python
def test_spaces(env):
    obs, info = env.reset(seed=0)
    assert env.observation_space.contains(obs)
    assert env.action_space.n == 6 and info["playing"] and info["score"] == 0

def run_episode_prefix(env, seed):
    obs, _ = env.reset(seed=seed)
    obs_list, rewards = [obs], []
    for a in [3, 3, 1, 5, 5, 2, 0, 4] * 10:
        o, r, *_ = env.step(a)
        obs_list.append(o); rewards.append(r)
    return obs_list, rewards

def test_reset_seed_reproducible(env):
    (oa, ra), (ob, rb) = run_episode_prefix(env, 123), run_episode_prefix(env, 123)
    assert all(np.array_equal(x, y) for x, y in zip(oa, ob)) and ra == rb

def test_different_seeds_differ(env):
    # max_noop даёт разный старт: хотя бы для одной пары сидов из 5 первые наблюдения различаются
    assert any(not np.array_equal(env.reset(seed=s)[0], env.reset(seed=s + 100)[0]) for s in range(5))

def test_score_reward_positive_when_bricks_hit(env):
    env.reset(seed=0)
    total = sum(env.step(1 if i < 3 else 0)[1] for i in range(400))  # запуск мяча, ракетка стоит
    assert total != 0   # мяч бьёт кирпичи (+) и/или теряется жизнь (-)

def test_game_over_terminates(env):
    env.reset(seed=0); terminated = False
    for i in range(20_000):
        *_, terminated, truncated, info = env.step(0)
        if terminated: break
    assert terminated and not info["playing"]

def test_score_glitch_gives_no_reward():
    # чистая функция награды: (prev ScreenState, cur ScreenState) -> float
    from neuronoid.env import reward_between, ScreenState
    s = lambda sc, lv=2, rd=1: ScreenState(True, sc, rd, lv)
    assert reward_between(s(100), s(None)) == 0
    assert reward_between(s(None), s(12000)) == 0
    assert reward_between(s(12000), s(0)) == 0
    assert reward_between(s(100), s(200)) == pytest.approx(1.0)
    assert reward_between(s(100, lv=2), s(100, lv=1)) == pytest.approx(-1.0)
    assert reward_between(s(100, rd=1), s(100, rd=2)) == pytest.approx(10.0)

def test_check_env(env):
    from gymnasium.utils.env_checker import check_env
    check_env(env, skip_render_check=True)
```

  `reward_between(prev: ScreenState, cur: ScreenState) -> float` — чистая функция в `neuronoid/env.py`, которой пользуется `step`. Для сравнения счёта она хранит последнее **прочитанное** значение, поэтому в `step` передаётся `prev` с последним известным счётом; `None` в `cur.score` не сдвигает это значение.

  - `ArkanoidEnv(live=True)` после каждого `step`/`reset` вызывает `publish` с последним кадром 320×200 и `info`.
  - `scripts/watch.py [--scale 3]` — окно pygame 960×600, ~70 кадров/с: показывает последний кадр и строку «счёт / раунд / жизни / кадр N». Нет публикатора — пишет в окне «ждём обучение…» и пытается переподключиться раз в секунду. Закрытие окна не влияет на обучение.
  - `scripts/play_random.py [--steps N]` — `ArkanoidEnv(live=True)`, случайные действия, печать суммарной награды за эпизоды и шагов в секунду.
